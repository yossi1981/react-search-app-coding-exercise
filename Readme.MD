# Recipe Search App
This is a recipe search application built with React.

The app uses an [spoonacular API](https://spoonacular.com/) to fetch the first available recipe, upon search.
The api key in the source code is not valid.
You can create your own api key and test this app.

## Features

- **Search Recipes**: Find recipes by entering ingredients or keywords.
- **Filter Results**: Filter search results by dietary preferences such as vegetarian, vegan, gluten-free, etc.
- **Save Favorites**: Save your favorite recipes for easy access later.
- **Detailed Instructions**: View detailed cooking instructions and ingredient lists for each recipe.

## Installation

To install and run the Recipe Search App locally, follow these steps:

1. **Clone the repository**:
    ```bash
    git clone https://github.com/yourusername/recipe-search-app.git
    ```
2. **Navigate to the project directory**:
    ```bash
    cd recipe-search-app
    ```
3. **Install dependencies**:
    ```bash
    npm install
    ```
4. **Start the application**:
    ```bash
    npm start
    ```

## Usage

1. Open your web browser and navigate to `http://localhost:3000`.
2. Use the search bar to enter ingredients or keywords.
3. Apply filters to narrow down the search results.
4. Click on a recipe to view detailed instructions and ingredients.
5. Save your favorite recipes for quick access.
